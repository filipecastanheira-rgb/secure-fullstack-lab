# Security Policy

## Supported Versions

The `main` branch is the only supported version of this project. Security
patches will be applied there.

## Reporting a Vulnerability

This lab is a portfolio project and is not intended to be exposed to the
Internet. However, if you find a security issue in the code or the
documentation, please report it responsibly.

**Do not open a public issue.** Instead, contact the maintainer directly:

- Email: filipecastanheira@gmail.com

Please include:
- A description of the issue
- Steps to reproduce (if applicable)
- The potential impact

## What to Expect

As this is a single-operator lab, response times are best-effort:
- **Acknowledgment:** within 72 hours
- **Initial assessment:** within 7 days

If the issue is confirmed, a fix will be prioritised according to the
vulnerability management policy (`docs/vulnerability-management-policy.md`).

## Out of Scope

- Physical attacks against the host machine
- Social engineering
- Denial of Service (DoS) attacks against the local network
